# V2 foundation overview

The owner selected PR #28 as the single Stage 0–1 delivery candidate on 2026-10-24 after comparing PR #29. This overview is a navigation aid, not another curriculum authority or a claim that the complete v2 course is implemented.

## Direction

**Engineering at the Speed of AI:** connect multidisciplinary engineering knowledge with bounded AI-assisted work while retaining engineering judgment, reviewable changes and qualified evidence.

- Planning, exploration and delivery form connected feedback loops; see [engineering workflow](../../project/ENGINEERING-WORKFLOW.md).
- Progressive specifications expose known constraints and unresolved questions; see [tutorial specification](../../project/TUTORIAL-SPEC.md).
- Software, electronics, mechanical work and physical verification have different cadences; see [demonstrator learning plan](../../project/DEMONSTRATOR-LEARNING-PLAN.md).
- Agent context, tool availability and human authority are distinct; existing V0 sources and tests remain protected by [repository guidance](../../AGENTS.md).

## One curriculum, staged delivery

The [curriculum map](../../project/CURRICULUM-MAP.md) is the single proposed twelve-chapter/four-part plan. [Chapter briefs](../../chapters/) define future slices. Home and Learn present planned topics separately from the twelve published original lessons; the completed chapter registry remains unchanged.

This foundation changes Home/Learn framing and adopts proposed design documents. It introduces no new v2 lesson, model, agent runtime, physical measurement or governance integration. V0's expected geometric FAIL remains distinct from passing software checks.

Use [adoption status](ADOPTION-STATUS.md) for reconciled conflicts and migration policy, [verification](VERIFICATION.md) for actual observations, and the [delivery plan](../../implementation/IMPLEMENTATION-PLAN.md) for separately scoped later stages. Owner authorization to publish this foundation does not authorize automatic delivery of those later stages.

## Consolidation

PR #29's concise overview approach informed this linked entry point. Its page implementations were not merged or cherry-picked: the primary candidate retains shared planned data, continuous numbering, clear status labels and the historical Home anchor. Both candidates passed 86 tests and generated the same expected V0 outcome during comparison. The comparison did not include a new visual/accessibility audit of #29.
