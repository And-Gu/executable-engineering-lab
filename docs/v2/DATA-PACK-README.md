# Executable Engineering Lab — Agent data pack

Version 1.0 candidate · 2026-10-20. This is a **complete proposed educational specification package**, not a deployed repository change or completed site rewrite.

## Start here

1. `project/TUTORIAL-SPEC.md` — core thesis and reader promise.
2. `project/CURRICULUM-MAP.md` — flexible ten-chapter/four-part sequence.
3. `project/ENGINEERING-WORKFLOW.md` — roadmap, dual loops, progressive specification, agent authority, integration.
4. `project/DEMONSTRATOR-LEARNING-PLAN.md` — DMS evolution and cross-discipline examples.
5. `project/EDITORIAL-GUIDE.md` and `project/INFORMATION-ARCHITECTURE.md` — voice, visuals and source structure.
6. `project/DECISIONS.md` — adopted direction and unresolved choices.
7. `AGENTS.md`, `agents/`, `templates/`, `prompts/` — collaboration instructions and execution workflows.

## Recommended usage

Upload/commit the package as a **documentation-only adoption PR** using `prompts/06-RECONCILE-AND-ADOPT.md`. Do not replace existing code, V0 engineering specs or existing Chapter 1 routes blindly. Once the user accepts repository adoption, run chapter work with `prompts/05-CREATE-CHAPTER-BRIEF.md` followed by bounded design/implementation and editorial review.

## New governing choices

AI-native, cross-disciplinary *engineering*; agentic focus stronger than digital-thread history; chapter on planning; exploration and delivery in parallel; progressive spec without waterfall; small reviewable changes; integrated information but diverse cadence; software often releasable, hardware controlled with physical readiness; actual source-backed evidence and human authority.

## Applicability

The generic `templates/TUTORIAL-SPECIFICATION-TEMPLATE.md` and original starter prompts remain reusable **templates**. Project-specific `project/` documents take precedence for this site. `DEMONSTRATOR_SPEC.md` in the live repo is the authoritative implemented V0 contract, not superseded by example staging here.
