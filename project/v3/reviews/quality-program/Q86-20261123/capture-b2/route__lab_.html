Definition and interpretation

REQ-COV-001 defines the 50% criterion. This threshold is a teaching assumption, not an operationally derived target. TEST-COV-001 evaluates the reference scenario using MODEL-COV-001 v0.1.0.

Method: cell-center-grid, 100 × 100 equal-area cells. A cell is covered when its center’s distance is ≤ radius; zero radius means zero coverage. This is a sampled estimate, with discretization error. The smooth circle depicts the ideal footprint, not the sampled cells. PASS uses the unrounded estimate and includes equality.

  • One fixed ideal circular footprint in a uniformly weighted rectangular area.
  • No terrain, occlusion, uncertainty, time, faults, or communication effects.

No directional sensitivity or real sensor calibration is modeled. Area coverage is not detection probability, tracking performance or mission effectiveness. A PASS only satisfies this idealized geometric criterion.
