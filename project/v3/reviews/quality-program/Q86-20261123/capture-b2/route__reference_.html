The original single-sensor model

The coverage lab starts from the scenario below. Follow the IDs from stakeholder need through the numerical estimate and its evaluation.

  1. NEED-001 is the source need of REQ-COV-001.
  2. The requirement is evaluated under SCN-001 using MODEL-COV-001.
  3. TEST-COV-001 evaluates that reference configuration against the requirement’s threshold.
  4. An evidence execution creates a RESULT-* record with the inputs, result, model version, source commit and run context. The validation workflow retains these as downloadable CI artifacts for 30 days. No saved CI result is displayed here.

These are different relationships, not a general-purpose knowledge graph. A browser what-if run is temporary, and a changed configuration is no longer the unmodified reference scenario.

Proposal analysis is a different record

The same validation runs retain a separate proposal-analysis-<commit> artifact. Download a chosen revision’s JSON and inspect definition.baseline, definition.proposed, differences, calculation and execution context. Its kind is unapproved-proposal-analysis and verification.testExecuted is false: it does not claim TEST-COV-001 verified the proposal.

These artifacts also expire after 30 days and may require GitHub sign-in. Reproduce them at the intended revision with npm ci, npm run check and npm run proposals. Browser proposals never create these retained records.

Inspect a retained reference evaluation record

npm run evidence calculates and evaluates canonical inputs; it does not itself invoke Vitest. The record’s test ID associates the registered reference context. Inspect the separate test command and workflow logs to establish assertion execution. Reproduce and review both activities.

  1. Open the main-branch validation runs and select a successful run for the revision you want to inspect.
  2. Download its reference-evidence-<commit> artifact (GitHub sign-in may be required). Artifacts expire after 30 days.
  3. Open reference-evidence.json. Check execution.sourceCommit, runTimestamp, workingTreeDirty and context before interpreting definition and calculation.

The record includes exact inputs, model version, sampling method/resolution, threshold, result and requirement outcome. No live “latest PASS” is implied by this page. If an artifact has expired, reproduce a local record with npm ci, npm test and npm run evidence at the intended source revision; that new run has its own timestamp and context.

MODEL-COV-001

Definition: executable model · models/coverage/coverage.ts

import { coverageInputSchema } from '../../schemas/engineering.js';
import type { z } from 'zod';
export type CoverageInput = z.infer<typeof coverageInputSchema>;
export type Area = CoverageInput['area'];
export type Sensor = CoverageInput['sensor'];
export const MODEL_VERSION = '0.1.0';
export const GRID_WIDTH = 100;
export const GRID_HEIGHT = 100;
export type CoverageResult = {
  coveredCells: number; totalCells: number; coveragePercent: number;
  method: 'cell-center-grid'; gridWidth: number; gridHeight: number;
};
/** Fixed 100×100 equal-area cell centers; disk boundary is inclusive.
 * An estimate of area fraction, not detection probability or exact geometry.
 */
export function calculateCoverage(input: CoverageInput): CoverageResult {
  const { area, sensor } = coverageInputSchema.parse(input);
  let coveredCells = 0;
  // Radius zero is explicitly zero coverage, even at a cell center.
  if (sensor.radius > 0) {
    for (let row = 0; row < GRID_HEIGHT; row++) {
      const y = ((row + 0.5) / GRID_HEIGHT) * area.height;
      for (let col = 0; col < GRID_WIDTH; col++) {
        const x = ((col + 0.5) / GRID_WIDTH) * area.width;
        // hypot avoids overflow from squaring otherwise valid finite inputs.
        if (Math.hypot(x - sensor.x, y - sensor.y) <= sensor.radius) coveredCells++;
      }
    }
  }
  const totalCells = GRID_WIDTH * GRID_HEIGHT;
  return { coveredCells, totalCells, coveragePercent: 100 * coveredCells / totalCells,
    method: 'cell-center-grid', gridWidth: GRID_WIDTH, gridHeight: GRID_HEIGHT };
}

TEST-COV-001

Definition: verification test · models/coverage/verification.test.ts

import { expect, it } from 'vitest';
import { loadSources } from '../../scripts/sources.js';
import { calculateCoverage } from './coverage.js';
import { evaluateCoverage } from './evaluate.js';
it('TEST-COV-001: evaluates REQ-COV-001 independently of the site', () => {
  const { requirement, scenario } = loadSources();
  const result = calculateCoverage({ area: scenario.area, sensor: scenario.sensor });
  const evaluation = evaluateCoverage(result, requirement.threshold_percent);
  expect(result.coveragePercent).toBeGreaterThan(38);
  expect(result.coveragePercent).toBeLessThan(39);
  expect(requirement.threshold_percent).toBe(50);
  expect(evaluation.pass).toBe(false);
  expect(evaluation.marginPercentagePoints).toBeLessThan(0);
});

Evaluation rule

import { percentSchema } from '../../schemas/engineering.js';
import type { CoverageResult } from './coverage.js';
/** Compare the unrounded estimate. Equality passes. */
export function evaluateCoverage(result: CoverageResult, requiredPercent: number) {
  const measured = percentSchema.parse(result.coveragePercent);
  const threshold = percentSchema.parse(requiredPercent);
  return { pass: measured >= threshold, marginPercentagePoints: measured - threshold };
}
